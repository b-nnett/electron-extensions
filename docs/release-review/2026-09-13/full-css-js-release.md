## What the mixed runtime now does

- CSS and JS remain separate ordered arrays in the manifest. The runtime applies CSS before running the extension's JS files in manifest order. Stored source is preserved even when the selected profile cannot enable it. Enabled bounds include 64 KiB combined CSS, 256 KiB combined JS, 64 records per app and 32 files per record.
- Scripts receive the lexical `ea.id`, `ea.signal`, `ea.onDispose(callback)` and attributed `console.log/info/warn/error` contract. Unchanged library polls do not reinstall an active revision. Disable, removal and replacement abort the instance and run registered cleanup; disposal failure blocks that affected extension's replacement until a fresh document, while other extensions can continue.
- Cleanup supports cooperative Promise-returning callbacks with bounded deadlines. It cannot undo arbitrary external side effects, discover unmanaged resources or interrupt a synchronous infinite loop. The [authoring contract](../../EXTENSION-FORMAT.md) specifies the actual behavior.
- Brokers persist bounded extension/file/revision-attributed log events to the native session. Details separates **Runtime** from **Library** logs and reports missing or invalid runtime evidence honestly. The positive native proofs use the same runtime-log reader as Details.
- An active older helper that cannot execute imported JS is preserved before any incompatible library write. Native import/toggle flows offer a normal **Restart / Not Now** upgrade path, using the existing process identity and expected-library checks. [Implementation and synthetic verification](active-helper-javascript-upgrade.md).
- The catalog's engine declaration enables imported JS selection and the shared renderer controller; launch flags remain unchanged. Slack, Notion and Figma now permit paths on their exact configured HTTPS origins, with source tests rejecting other origins; this does not verify signed-in screens. Other profiles keep their configured route patterns. ChatGPT binds its built-in experimental adapter to one exact main app page and rejects ambiguous page selection. Target ownership and installation identity checks remain enforced. No installed bundles, target signing/entitlements/fuses or Chrome extension APIs are changed.
